# e_comm_olist
Este repositório contém uma aplicação web analítica e interativa desenvolvida em Python e Streamlit, projetada para explorar, analisar e manipular dados do ecossistema de e-commerce brasileiro.O diferencial técnico deste projeto está na fusão da Análise de Dados com a Engenharia de Software, utilizando Programação Orientada a Objetos (POO).
